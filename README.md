# Algorithm Analysis

A small Python demonstration of merge sort applied to product records. The script sorts the same product list by price, popularity, rating, and release date to show how a comparison criterion changes ordering.

## Run

```bash
python Code.py
```

## Contents

- `merge_sort(products, criteria)` recursively divides the input.
- `merge(left, right, criteria)` combines sorted partitions.
- The example dataset exercises numeric and date-based criteria.

## Requirements

Python 3; no third-party packages are required.
